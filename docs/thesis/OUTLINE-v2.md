# 《“车鉴 CarLens”多品牌汽车配置聚合与在线报价平台的设计与实现》论文提纲 v2

> 按 2027 届计算机科学与技术、广州华立学院毕业设计要求整理；对应线上 Demo v0.9（10 品牌 / 20 款车型）。

## 摘要 / 关键词

- 中文摘要 400–600 字：多品牌配置聚合、统一报价口径、3D/2D 配置器、服务端计价、模拟支付、后台运营。
- 关键词：多品牌聚合；汽车配置器；在线报价；Fastify；Vue 3；SQLite
- 英文摘要与关键词对应翻译。

## 第 1 章 绪论

1.1 研究背景：多品牌选车信息分散、配置与落地价口径不一致。
1.2 研究意义：把“选车—配置—报价—下订—试驾”放进一个入口；院校毕设的工程训练价值。
1.3 国内外现状：汽车垂直媒体、品牌官网配置器、聚合平台；各自优缺点。
1.4 研究内容与论文结构。

## 第 2 章 相关技术

2.1 前后端分离与 Vue 3 / TypeScript / Vite / Pinia。
2.2 Fastify 5 + Zod + Drizzle ORM + SQLite。
2.3 three.js / GLTFLoader / KTX2 / Reflector 的 3D 展示。
2.4 服务端计价与整数分精度；JWT/Cookie、限流、CSP。
2.5 本章小结。

## 第 3 章 需求分析

3.1 角色：访客、登录用户、运营管理员。
3.2 功能需求：车型矩阵/详情、配置器、报价单、下订与模拟支付、订单、试驾、门店、金融、新闻、后台。
3.3 非功能需求：移动端适配、首屏性能、价格一致性、安全性、可部署性。
3.4 用例图与核心流程（选车 → 配置 → 报价 → 下订 → 支付 → 订单）。
3.5 本章小结。

## 第 4 章 系统设计

4.1 总体架构：Web / API / SQLite / 静态资源 / nginx + Cloudflare Tunnel。
4.2 数据模型：品牌—车型—版本—车漆/轮毂/内饰/选装包—订单/试驾/新闻；当前 20 车型、45 版本、260 条车型选装关系。
4.3 计价模型：裸车、购置税、保险、上牌、定金；taxFull、taxRelief、insurance 公式。
4.4 配置器设计：共享 3D 模型 + 2D 海报切换；model_paint_images 支撑按颜色换图。
4.5 接口设计：REST 路由、统一错误信封、Zod 校验、限流。
4.6 移动端与响应式设计：390/360 审计、对比页卡片化、轮播控件。
4.7 本章小结。

## 第 5 章 系统实现

5.1 车型目录与多品牌数据组织（brand 字段/品牌筛选）。
5.2 配置器与实时报价：Pinia 状态、服务端复算、规则校验。
5.3 订单与模拟支付：快照、状态机、支付归属校验。
5.4 试驾/门店/金融/新闻/账户/后台。
5.5 3D 场景与性能：模型复用、KTX2、bloom、2D 降级。
5.6 AI 换色海报流程：基准图、局部重绘、审核入库、API 回退。
5.7 部署与运维：rsync、systemd、nginx、健康检查、备份。
5.8 本章小结。

## 第 6 章 系统测试与部署

6.1 测试环境与工具：Vitest、Puppeteer、vue-tsc、vite build。

6.3 兼容性/移动端测试：1440/1024/390/360，无横向溢出。
6.4 安全测试：限流、越权、CSP、输入校验。
6.5 部署与线上验收：https://ziphare.me/。
6.6 本章小结。

7.1 工作总结。
7.2 不足：20 款仍是演示规模、共享 3D 模型、AI 换色图待补（目前 2 款完成）。
