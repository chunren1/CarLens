## 最新选题（表里已填）

**题目：** 《“车鉴 CarLens”多品牌汽车配置聚合与在线报价平台的设计与实现》

**平台名：** 车鉴（CarLens）

**核心：** 多源异构车型数据归一化 → 跨品牌检索/筛选/对比 → 配置与报价适配 → 来源标注/后台运营。

**数据规模：** 目标 8–10 个品牌、20+ 车型；示例：比亚迪海豹/汉 EV、特斯拉 Model 3/Model Y、蔚来 ET5/ES6、小鹏 P7+/G6、理想 L6/L7、极氪 001/007、小米 SU7、问界 M5/M7、埃安 AION S/Y、零跑 C10/C11。
