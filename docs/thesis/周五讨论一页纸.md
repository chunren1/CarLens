## 三、项目怎么改

- 新增购车闭环：配置 → 报价 → 下订（选门店、填信息、确认定金）→ 模拟支付 → 订单跟踪 → 后台订单管理。
- 新增金融方案计算器：首付比例、期数、年化利率 → 月供、总利息。
- 新增门店查询、车主服务、品牌故事、新闻页，补齐 BBA 式官网结构。
- 数据表 15 → 17（加 orders、payments）；接口 12 → 16 个以上。
- 时间线：M4 购车闭环与后台（2 月）→ M5 上线（3 月上）→ 3-31 功能冻结。

## 五、老师可能问的五个问题

1. **还是车贩子吗？**
   → 不是。标题沿用“配置与报价”，但系统是品牌官方直营站：配置、价格、订单全透明，用户直接在官网下订。车贩子是经销商撮合报价，两者的业务链路不同。

2. **支付真的接吗？**
   → 只做模拟支付网关，跳转页面，不接支付宝/微信商户、不产生扣款；页面标注“演示环境 · 模拟支付”，论文写“支付流程与订单状态机验证”。

3. **仿 BBA/BYD 仿到什么程度？**
   → 导航、车型矩阵、配置器、金融方案、门店查询、预约试驾、车主服务、品牌/新闻、订单中心，结构对齐；视觉自研，不抄素材。

4. **工作量够吗？**
   → 4 款车型、17 张表、16+ 接口、规则/价格/订单状态机、金融计算器、后台；正文 ≥8000 字，按需求—设计—实现—测试—部署组织。

5. **和“家用汽车选购系统”有什么区别？**
   → 它是通用选车网站；我们是官方直营购车系统，核心是配置约束、透明报价、下订/支付/订单闭环。
